# Cursor source

`cursor_arrow_14x22.png` is the small transparent arrow cursor from Wikimedia
Commons, downloaded from:

<https://commons.wikimedia.org/wiki/File:Mouse_pointer_small.png>

The file page identifies the image as a simple transparent mouse pointer and
places it in the public domain. The storage build converts it to row-major
`RGBA8888` bytes and records it under the label `cursor_arrow_rgba8888`.
