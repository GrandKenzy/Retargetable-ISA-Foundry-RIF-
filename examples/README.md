# RIF examples

- [AMD64](./AMD64/README.md): raw AMD64 `sys_exit(42)` bytes.
- [AMD64 Linux v3](./AMD64-Linux-v3/README.md): target AMD64 amplio con
  tablas de registros, REX/ModRM/SIB, memoria, condiciones, ELF64 y
  relocaciones simbólicas.
- [GBA Bouncing Ball](./GBA-Bouncing-Ball/README.md): ROM GBA ARM7TDMI con
  header, código ARM, variante Thumb y una pelota rebotando en Mode 3.
- [ELF64](./ELF64/README.md): a minimal executable Linux ELF64 image built
  with inserts and final header patches.
